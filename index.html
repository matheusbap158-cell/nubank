O que perguntam.

Este é o site oficial do Nubank?

Não. É um projeto conceitual independente, criado pela Connect Alpha para mostrar direção de arte e jornada de rolagem. Não tem relação, patrocínio nem aprovação do Nubank.

Os valores e o cartão são reais?

Não. Limite, Pix, caixinhas e nome no cartão são ilustrações para o conceito. Nada aqui é oferta de produto financeiro.

Dá para virar o cartão?

Dá. Toque no cartão (ou no botão "Virar o cartão") e ele gira. Ele também acompanha o movimento do mouse.

Dá para fazer algo assim para a minha marca?

Dá. Uma jornada com um objeto central que se transforma pode ser criada para qualquer negócio. Chame a Connect Alpha no WhatsApp.
